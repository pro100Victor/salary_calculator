## Реализация инженера 3

Инженером 3 выполнена сборка компонентов минимального прототипа `Salary Calculator` в единое консольное приложение. Создан файл `src/main.py`, который является единой точкой входа, создаёт необходимые сервисы и передаёт их консольному интерфейсу. Бизнес-логика и пользовательский ввод в точке входа отсутствуют.

Проект настроен с помощью менеджера пакетов `uv`. В файле `pyproject.toml` зафиксирована поддержка Python 3.11 и выше, добавлены требуемые условиями лабораторной работы зависимости FastAPI, SQLAlchemy, Alembic и Pydantic. Эти библиотеки не используются в исходном коде текущего этапа, поскольку программа должна быть реализована средствами ванильного Python. Для разработки добавлены Ruff и Pytest.

Настроен Ruff для проверки импортов, синтаксических ошибок, неиспользуемых объектов и соответствия кода актуальной версии Python. Добавлен `.gitignore`, исключающий виртуальное окружение, кэш Python, кэш инструментов и файлы сред разработки.

Разработаны интеграционные тесты, которые проверяют совместную работу настоящих компонентов инженеров 1 и 2. Проверяется полный сценарий: создание сотрудника, ввод отработанных смен, расчёт начисления, удержание НДФЛ 13 процентов и вывод итоговой суммы к выплате через CLI.

Подготовлены документы с описанием архитектуры прототипа и планом штатных и внештатных испытаний. В плане отдельно рассмотрены ошибки ИНН, ставки, количества смен, превышения нормы и обращения к отсутствующим данным.

Файлы, реализованные инженером 3:

- `src/main.py` — единая точка входа и сборка зависимостей;
- `pyproject.toml` — параметры проекта, зависимости и настройки инструментов;
- `uv.lock` — зафиксированные версии зависимостей;
- `.gitignore` — исключения для Git;
- `tests/test_integration.py` — интеграционная проверка компонентов;
- `docs/ARCHITECTURE_LAB3.md` — описание архитектуры прототипа;
- `docs/TEST_PLAN_LAB3.md` — план штатных и внештатных испытаний.
