# Проверка штатного и внештатного поведения

1. Войти `admin/admin`, настроить организацию и должность с тарифом 2500 руб. и надбавкой 0%.
2. Добавить двух сотрудников с разными 12-значными ИНН, посмотреть справочник.
3. Выбрать месяц; при необходимости установить норму 22 смены и сформировать табель.
4. Заполнить каждому строку: 20 смен, 1 больничный, 1 отпуск; проверить итог 22 дня.
5. Рассчитать ведомость: начислено 50000, НДФЛ 6500, выплата 43500 на каждого; проверить общую сумму.
6. Посмотреть расчётный листок за период, изменить строку табеля, проверить статус «устарела», подтвердить перерасчёт и закрыть период.
7. Проверить запрет изменения закрытого табеля и повторного расчёта.

Внештатные тесты: неверный логин, пустые поля, неправильный/повторный ИНН, неверная дата, отсутствующая должность, отрицательная или дробная ставка, буквы вместо смен, отрицательные/дробные смены, превышение нормы суммой смен и отсутствий, незаполненная строка, несуществующий сотрудник, поиск листка без ведомости. Сервис должен сообщить причину, сохранить прежние корректные данные и продолжить работу.

В рамках CLI нет HTTP-ответа 400: ему соответствует сообщение об ошибке валидации, без завершения процесса. Не проводится ввод в базу данных и генерация PDF — эти проверки относятся к следующим этапам.
