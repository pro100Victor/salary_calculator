| Сценарий ТЗ | Работающая операция CLI | Отличие текущего этапа |
| --- | --- | --- |
| 3.3.1 Карточка сотрудника | Пункты 2–6: должности, создание, изменение, увольнение и просмотр | Модальное окно заменено вопросами терминала; данные хранятся InMemory. |

| 3.3.4 Расчёт начислений | Пункт 10: полная ведомость, НДФЛ, итоги и повторный расчёт | В базовой версии оплачиваются только фактические смены. |

Также реализованы учебный вход бухгалтера (перед меню) и закрытие периода (пункт 13). Все прочитанные и изменённые сведения существуют только в оперативной памяти. Веб-формы, REST API, PostgreSQL и контейнеры относятся к следующему этапу, а не к исполняемой программе ЛР №3.

При объединении с общим репозиторием пункты 1–4 ТЗ, ранее размещённые в корневом README для ЛР №1, необходимо сохранить. Содержимое README этого комплекта описывает только текущий работающий CLI и может быть добавлено после этих разделов; не удаляйте утверждённые сведения команды.
