# Архитектура прототипа для лабораторной работы №3

Программа разделена на независимые компоненты. `main.py` является точкой сборки и запуска. Он создаёт сервис сотрудников и сервис расчёта, после чего передаёт их консольному интерфейсу.

Консольный интерфейс отвечает только за ввод и вывод данных. Он не содержит формул расчёта и не хранит сотрудников. `EmployeeService` проверяет и хранит сотрудников в оперативной памяти. `PayrollService` проверяет сведения о сменах и координирует расчёт начисления и НДФЛ. Модели используются для передачи данных между компонентами.

Общий порядок взаимодействия компонентов:

```text
Пользователь
    ↓
CLI
    ↓
EmployeeService и PayrollService
    ↓
InMemory-список и расчётные классы
```

Такое разделение позволяет заменять способ взаимодействия с пользователем или добавлять новые схемы оплаты без переписывания остальных компонентов.

На текущем этапе база данных, веб-сервер и внешнее хранилище не используются. Все сведения существуют только во время работы процесса Python.
