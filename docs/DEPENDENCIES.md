# Зависимости и запуск

Основной список — `pyproject.toml`, точные версии — `uv.lock`. В обновлении добавлены через uv сервер `uvicorn` и dev-зависимость `httpx` для HTTP-тестов; lock-файл пересчитан. `requirements.txt` — только дополнительный простой список runtime-библиотек, не отдельный lock.

| Пакет | Назначение |
| --- | --- |
| fastapi | HTTP-адаптер существующих сервисов, выдача статических файлов. |
| pydantic | Типы и структура входных HTTP-данных. |
| uvicorn | Запуск ASGI-приложения. |
| sqlalchemy, alembic | Заявлены в исходном проекте; интеграцию БД делают инженеры 1 и 3. |
| pytest, ruff | Тестовый запуск, проверка/форматирование Python. |
| httpx (dev) | TestClient для проверок HTTP. |

Установка из обновлённого проекта: `uv sync`. Веб: `uv run python src/web_main.py`. CLI: `uv run python src/main.py`. Для нового драйвера PostgreSQL инженер 3 выполняет `uv add "psycopg[binary]"`.

В проекте оставлены нижние границы FastAPI, SQLAlchemy, Pydantic и Alembic из исходного архива. Разрешение зависимостей и создание окружения проверяются отдельно; при недоступности версий на зеркале PyPI сначала проверьте источник пакетов, не меняйте версии случайно.

В исходном архиве `requirements.txt` был файлом формата DOCX. Он сохранён как `docs/requirements_original.docx`; новый requirements.txt содержит обычный текст.
