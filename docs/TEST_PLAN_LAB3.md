# План проверки прототипа

## Штатное поведение

1. Запустить программу.
2. Добавить сотрудника с корректными ФИО, ИНН, должностью и ставкой.
3. Открыть список сотрудников и проверить созданную запись.
4. Выбрать расчёт заработной платы.
5. Ввести норму 22 смены и 20 отработанных смен.
6. Проверить начисление, НДФЛ 13 процентов и сумму к выплате.
7. Повторно открыть сформированный расчётный листок.
8. Завершить работу через пункт главного меню.

Для ставки 2500 рублей ожидается следующий результат:

- начислено — 50000 рублей;
- НДФЛ — 6500 рублей;
- к выплате — 43500 рублей.

## Внештатное поведение

Необходимо проверить:

- пустое ФИО;
- ИНН с буквами или неправильной длиной;
- повторяющийся ИНН;
- пустую должность;
- нулевую и отрицательную ставку;
- буквы вместо чисел в меню и расчётных полях;
- отрицательное количество смен;
- количество смен больше нормы;
- поиск несуществующего сотрудника;
- попытку просмотреть листок до выполнения расчёта.

Во всех перечисленных случаях программа должна вывести понятное сообщение и продолжить работу без аварийного завершения.
